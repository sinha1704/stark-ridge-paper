# Stark Ridge Paper

An interactive product showcase and specimen feed for Stark Ridge Paper Co., designed with Next.js (App Router), Tailwind CSS, and hardware-accelerated 3D CSS / GSAP transitions.

## Features

- **Specimen Card Feed**: Responsive layout showcasing manufactured paper grades (Virgin Kraft, Fluting Medium, Rigid Boards, and Aqueous Barriers).
- **Interactive 3D Datasheet Flip**: 60fps GPU-accelerated card flipping revealing basis weights (GSM), calipers, surface finishes, and environmental standards.
- **Category Filter**: Multi-row responsive filter for rapid category inspection.
- **Responsive Architecture**: Fully optimized across desktop, tablet, and ultra-compact mobile viewports (down to 320px).

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) v4
- **Animation**: [GSAP](https://gsap.com/) & hardware-accelerated 3D transforms
- **Icons**: Lucide React
- **Typography**: Google Fonts (Plus Jakarta Sans, Playfair Display)

## Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build
